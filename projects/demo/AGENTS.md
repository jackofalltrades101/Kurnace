# AGENTS.md — Kurnace project conventions

_Generated by `kurn`. Regenerate with `kurn agents-md`._

## Rules
- Change the timeline **only through `kurn`** (`kurn op <type> --args <json>`, `kurn op batch`, `kurn undo`). Never edit `timeline.json`, `board.excalidraw`, `.ws/`, or the library directly; both snapshots are exports and will be overwritten.
- Storyboard on the board: `kurn board add --json '[…]'`, `kurn board frame <name> --at x,y`, `kurn board snapshot --png renders/board.png`, `kurn board to-timeline`.
- You may edit `scenes/`, `modules/`, `storyboard.yaml`, `brief.md`.
- **Look before you claim.** After any visual change run `kurn render still --frame N` and inspect the PNG. Never judge from the preview.
- Times are **integer frames** at the project fps. Keyframe `t` is clip-local.
- Group related edits into one `kurn op batch` (atomic, one undo step).
- Destructive ops (track.remove, ripple.delete, removing >5 clips) return exit code 3 and wait for a human: `kurn op wait <id>`.
- You can't delete library assets; use `kurn lib deprecate`.
- Identify yourself: set `KURN_ACTOR=agent:<name>`.
- Publish your cursor so the human sees where you are: `kurn presence set --playhead <frame> --select c_1,c_2` (repeat or `kurn presence clear` when done).
- API modules are budgeted by `[agents].api_budget_usd`; check `kurn budget` and never bypass with `KURN_BUDGET_OVERRIDE` unless a human asked.
- Package a finished render with `kurn run export.mp4 --input renders/final.mp4 --preset youtube --out renders/youtube.mp4`.

## Rendering
```
kurn render still --frame 240          # → renders/f240.png
kurn render draft --range 0-300 --scale 0.5
kurn render final
```

## Ops (`kurn op <type> --args '<json>'`)
- `timeline.set` {duration?, width?, height?, fps?: {num, den}}
- `track.add` {kind, id?, name?, order?} → {track}
- `track.remove` {track}  (removes its clips; destructive)
- `track.reorder` {track, order}
- `track.set` {track, name?, muted?, locked?}
- `clip.add` {track, asset? | component?, start, in?=0, out? | dur?, props?, keyframes?, id?} → {clip}
- `clip.remove` {clip}
- `clip.move` {clip, start? | by?, track?}
- `clip.trim` {clip, in?, out?, start?}
- `clip.split` {clip, at}  (timeline frame) → {left, right}
- `clip.set` {clip, props?: {k: v|null}, asset?, offset_samples?}
- `keyframe.set` {clip, prop, t, v, ease?}  (t is clip-local)
- `keyframe.remove` {clip, prop, t?}  (no t = whole lane)
- `marker.add` {t, label, id?} → {marker}
- `marker.remove` {marker}
- `transition.set` {between: [a, b], type, dur} → {transition}
- `transition.remove` {transition}
- `ripple.delete` {clip}  (remove and close the gap on its track; destructive)
- `batch` {ops: [op, …]}  one transaction, one undo step

## Modules (`kurn run <id> --<input> <value>`)

### `audio.clean` — generator
Denoise (DeepFilterNet if installed) + highpass, EQ, compression, de-ess and two-pass loudness normalization, from a named preset
- `--denoise` (bool, default true)
- `--input` (asset, required)
- `--preset` (string, default "voice-narrator")
- `--target_lufs` (number, -30–-6)
- cost: local

### `export.mp4` — exporter
Package a rendered video for a destination: youtube (1080p pad), vertical (1080x1920 crop), square, or web
- `--crf` (integer, default 20, 0–51)
- `--input` (string, required)
- `--out` (string, required)
- `--preset` (string, default "youtube")
- cost: local

### `gen.python` — generator
Run a Python script that writes files into $KURN_OUT; every file it writes becomes a library asset (named by file stem). The script gets $KURN_ARGS (JSON) and the seed in $KURN_SEED.
- `--args` (json, default {})
- `--code` (string)
- `--file` (string)
- cost: local

### `godot.render` — generator
Render a C# Godot 4.7.2 project to a PNG frame sequence with the headless movie writer. Requires the Godot 4.7.2 .NET build; GDScript-only projects are rejected.
- `--fps` (integer, default 30, 1–120)
- `--frames` (integer, default 60, 1–1800)
- `--height` (integer, default 360, 16–4320)
- `--scene` (string, default "")
- `--source` (asset, required)
- `--width` (integer, default 640, 16–7680)
- cost: local

### `render.revideo` — renderer
Render a Kurnace timeline (or a frame range / still) with Revideo
- `--assets` (json, required)
- `--frame` (number, default 0)
- `--mode` (string, default "final")
- `--out` (string, required)
- `--range` (string)
- `--scale` (number, default 1.0, 0.1–1)
- `--timeline` (json, required)
- cost: local

### `three.render` — generator
Render a declarative three.js scene to a PNG frame sequence in headless Chromium
- `--file` (string)
- `--fps` (integer, default 30, 1–120)
- `--frames` (integer, default 60, 1–1800)
- `--height` (integer, default 360, 16–4320)
- `--scene` (json)
- `--width` (integer, default 640, 16–7680)
- cost: local

### `tts.fish` — generator
Generate voiceover from text via the Fish Audio API
- `--model` (string, default "")
- `--speed` (number, 0.5–2)
- `--text` (string, required)
- `--voice` (string, default "")
- cost: api

### `tts.say` — generator
Local voiceover with the macOS `say` command. Free, offline stand-in for tts.fish while developing.
- `--speed` (number, default 1.0, 0.5–2)
- `--text` (string, required)
- `--voice` (string, default "Samantha")
- cost: local
